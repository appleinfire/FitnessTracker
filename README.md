# Трекер тренировок

Веб-приложение для iPhone: считает повторения через фронтальную камеру.
Скелет распознаётся прямо на телефоне (MediaPipe Pose Landmarker), видео никуда не отправляется.

Открыть: https://appleinfire.github.io/FitnessTracker/

## Что уже есть

- Камера + скелет поверх видео.
- Приседания: по углу в колене (3D) или по высоте бёдер — переключается в настройках.
- Отжимания: по углу в локте или высоте плеч над руками; стоя не считает.
- Подтягивания: по положению головы относительно перекладины (запястий) или по углу в локте; повторение засчитывается наверху.
- Джампинг-джеки: руки над головой и ноги врозь (по положению запястий и щиколоток), засчитывается в верхней точке.
- Прыжки через линию (только в профиле Kids): светящаяся линия на полу от телефона к ребёнку, каждый перепрыг влево или вправо — повторение; режим «Линия едет» — линия проезжает по полу слева направо, нужно подпрыгнуть, когда она под ногами (скорость растёт с попаданиями); режим «Две (речка)» — две линии рядом, перепрыгнуть обе, не наступив между ними.
- Сглаживание сигнала и два порога (внизу/вверху) против ложных повторений.
- Подход заканчивается после паузы (5–10 с, настраивается) или если человек ушёл из кадра.
- История подходов хранится на телефоне (IndexedDB): сводка «Сегодня», экран истории по дням, правка и удаление подхода.
- Резервная копия в файл (JSON) и восстановление из неё без дублей; выгрузка таблицы CSV для Excel/Numbers.
- Облако (Supabase): вход по почте и паролю, история синхронизируется между устройствами; без интернета всё пишется на телефон и уходит в облако позже.
- Цель на день (каждый день или только на сегодня) — кольцо на главном экране, объявление при выполнении; перевыполнение — второй «огненный» круг и процент сверх цели.
- Главный экран: цель, упражнения, «Начать», журнал за сегодня; «Журнал» — вся история по дням; облако и резервная копия — в настройках.
- Профили «Я» и «Kids»: переключатель на главном экране, у каждого свой журнал, цель, рекорды и достижения (у Kids голубой акцент).
- Личные рекорды: «Новый рекорд!» во время подхода, список рекордов на экране «Прогресс».
- Достижения (16 наград, названия на английском) на экране «Прогресс», новые — в итогах тренировки.
- Экран не гаснет (Wake Lock, запасной вариант — беззвучное видео).
- Работает без интернета после первого открытия, можно поставить на экран «Домой».

## Как поставить на iPhone

1. Открыть ссылку выше в Safari.
2. Кнопка «Поделиться» → «На экран «Домой»».

## Файлы

- `index.html`, `css/style.css` — интерфейс.
- `js/app.js` — камера, главный цикл, подходы.
- `js/exercises.js` — как из скелета получить угол/высоту для каждого упражнения.
- `js/db.js` — хранение подходов в IndexedDB.
- `js/goal.js` — цель на день; `js/achievements.js` — достижения; `js/profile.js` — профили «Я» и «Kids».
- `js/cloud.js` — вход в облако и синхронизация с Supabase.
- `supabase/schema.sql` — таблица и правила доступа в Supabase (выполнить один раз в SQL Editor).
- `js/history.js` — экран истории, правка, экспорт и импорт.
- `js/counter.js` — сглаживание и счётчик с порогами.
- `js/pose.js` — загрузка модели и рисование скелета.
- `js/device.js` — «не гасить экран» и звуки.
- `sw.js`, `manifest.webmanifest` — офлайн-режим и иконка.
- `css/fonts.css`, `fonts/` — шрифты Fira Sans Extra Condensed и Onest (лицензия SIL OFL), лежат в приложении для офлайна.
- `vendor/mediapipe/` — библиотека MediaPipe Tasks Vision 1.0.1, `models/` — модели позы.
