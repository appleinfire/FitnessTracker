# Трекер тренировок

Веб-приложение для iPhone: считает повторения через фронтальную камеру.
Скелет распознаётся прямо на телефоне (MediaPipe Pose Landmarker), видео никуда не отправляется.

Открыть: https://appleinfire.github.io/FitnessTracker/

## Что уже есть

- Камера + скелет поверх видео.
- Приседания: по углу в колене (3D) или по высоте бёдер — переключается в настройках.
- Отжимания: по углу в локте или высоте плеч над руками; стоя не считает.
- Подтягивания: по положению головы относительно перекладины (запястий) или по углу в локте; повторение засчитывается наверху.
- Сглаживание сигнала и два порога (внизу/вверху) против ложных повторений.
- Подход заканчивается после паузы (5–10 с, настраивается) или если человек ушёл из кадра.
- Экран не гаснет (Wake Lock, запасной вариант — беззвучное видео).
- Работает без интернета после первого открытия, можно поставить на экран «Домой».

## Как поставить на iPhone

1. Открыть ссылку выше в Safari.
2. Кнопка «Поделиться» → «На экран «Домой»».

## Файлы

- `index.html`, `css/style.css` — интерфейс.
- `js/app.js` — камера, главный цикл, подходы.
- `js/exercises.js` — как из скелета получить угол/высоту для каждого упражнения.
- `js/counter.js` — сглаживание и счётчик с порогами.
- `js/pose.js` — загрузка модели и рисование скелета.
- `js/device.js` — «не гасить экран» и звуки.
- `sw.js`, `manifest.webmanifest` — офлайн-режим и иконка.
- `vendor/mediapipe/` — библиотека MediaPipe Tasks Vision 1.0.1, `models/` — модели позы.
